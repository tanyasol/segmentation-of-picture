# segmentation-of-picture

Учебный инструмент на C для обработки чёрно-белых снимков
(МРТ/КТ головного мозга): сегментация областей по яркости, удаление шума
и псевдораскраска отделов для наглядной визуализации.

---
## Возможности

- Загрузка и сохранение PNG (32-bit RGBA) через библиотеку
  [LodePNG](https://lodev.org/lodepng/).
- Перевод изображения в оттенки серого.
- Пороговое повышение контраста.
- Размытие по Гауссу.
- Сегментация по схожести яркостей через систему непересекающихся множеств
  (DSU / union-find).
- Удаление мелких шумовых областей по порогу площади.

---

## Алгоритм работы

```
load_png → rgb_to_bw → contrast → Gauss → make_comp → color → write_png
```

1. `load_png` — чтение PNG в буфер RGBA.
2. `rgb_to_bw` — перевод в оттенки серого по формуле BT.601.
3. `contrast` — пороговое повышение контраста (`< 55 → 0`, `> 195 → 255`).
4. `Gauss` — размытие по Гауссу ядром 3×3.
5. `make_comp` — сегментация: соседние пиксели с близкой яркостью объединяются
   в компоненты через DSU, мелкие компоненты удаляются.
6. `color` — каждая компонента получает цвет из палитры (12 оттенков,
   циклически).
7. `write_png` — сохранение результата в `rgb.png`.

## Сборка

### Требования

- Компилятор C (gcc / clang / MSVC).
- Файлы `lodepng.h` и `lodepng.c` рядом с `main.c`.
- Математическая библиотека (`-lm` на Linux/macOS).

### Linux / macOS

```bash
gcc -O2 -o brain_seg main.c -lm
```

### Windows (MinGW)

```cmd
gcc -O2 -o brain_seg.exe main.c -lm
```

### Windows (MSVC)

```cmd
cl /O2 /Fe:brain_seg.exe main.c
```

Реализация LodePNG подключается через `#include "lodepng.c"` прямо в `main.c`,
поэтому отдельный файл `lodepng.c` в команде сборки не указывается. Если позже
добавите второй `.c`-файл, который тоже подключает `lodepng.h`, получите
дублирование символов при линковке — тогда `#include "lodepng.c"` лучше убрать
и компилировать оба файла отдельно.

## Использование

1. Положите входной файл (по умолчанию `skull.png`) в директорию с исполняемым
   файлом.
2. Запустите:

   ```bash
   ./brain_seg
   ```

3. В директории появится `rgb.png` — результат раскраски.

Имя входного файла задаётся в `main()`:

```c
const char* input_file = "skull.png";
```

Имя выходного:

```c
write_png("rgb.png", res, width, height);
```

## Описание модулей

### Работа с изображением

| Функция | Назначение |
|---|---|
| `load_png` | Чтение PNG в буфер RGBA (32 бита на пиксель) |
| `write_png` | Запись RGBA-буфера в PNG |
| `rgb_to_bw` | RGBA → оттенки серого (BT.601) |
| `bw_to_rgb` | Ч/б → RGBA (серый во все каналы) |

### Фильтры

| Функция | Назначение |
|---|---|
| `contrast` | Порог: `< 55 → 0`, `> 195 → 255` |
| `Gauss` | Размытие по Гауссу 3×3 |
| `sharp` | Повышение резкости (не вызывается) |

### Сегментация

| Функция | Назначение |
|---|---|
| `makeset` | Инициализация DSU |
| `findset` | Поиск представителя со сжатием путей |
| `unionsets` | Объединение по рангу |
| `join` | Связывание соседних пикселей с близкой яркостью |
| `counter_comp` | Подсчёт размеров компонент |
| `del_noise` | Удаление областей меньше `min` |
| `make_comp` | Полный цикл сегментации |

### Раскраска

| Функция | Назначение |
|---|---|
| `color` | Назначение каждой компоненте цвета из палитры |

Палитра — 12 оттенков красно-розового спектра. Компоненты циклически
перебирают цвета.

## Настройка параметров

Все ключевые параметры задаются в `main()`.

| Параметр | Где | По умолчанию | Эффект |
|---|---|---|---|
| Нижний порог контраста | `contrast` | 55 | Ниже → больше чёрного |
| Верхний порог контраста | `contrast` | 195 | Выше → больше белого |
| `min` | `make_comp` | 25 | Минимальная площадь области |
| `dif` | `make_comp` | 5 | Порог схожести яркостей |

Рекомендации:

- Слишком много мелких пятен → увеличить `min` (до 100–200) и `dif` (до 10–15).
- Отделы сливаются → уменьшить `dif`.
- Тёмные ткани пропадают → уменьшить нижний порог `contrast` (55 → 30–40).
- Светлые ткани сливаются с фоном → увеличить верхний порог `contrast`
  (195 → 220).
